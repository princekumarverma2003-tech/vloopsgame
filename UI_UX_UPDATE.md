# VELoop Games — UI/UX Redesign

## What changed
- Redesigned the Games hub with a premium arcade visual system, stronger typography, reward-focused hero section, wallet cards, and responsive layouts.
- Added client-side game search and category filters.
- Improved game cards with stronger hierarchy, artwork treatment, hover states, and clearer CTAs.
- Refined shared header and bottom navigation for consistency across game screens.
- Updated the game detail page with a cleaner split hero, stronger entry-fee presentation, and responsive behavior.
- Updated the Redeem page with cleaner reward cards, spacing, typography, and modal styling.
- Added accessibility-minded focus states and reduced-motion support.
- Kept the existing game logic, routes, economy state, and assets intact.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The uploaded `node_modules` directory was intentionally excluded from the delivery ZIP because dependencies are platform-specific and should be recreated with `npm install`.
